The Markdown documents remain the authoritative public narrative. These files exist for reuse in rendered portfolio material.

## Diagram Conventions

- solid line = current/validated relationship;
- dashed line = planned/target relationship;
- public host identifiers only;
- documentation-only addressing only;
- no secrets, private paths, MAC addresses, serial numbers, or live DNS;
- protocol/port labels only when they carry security meaning.
