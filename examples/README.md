# Sanitized Examples

Examples in this directory are intentionally partial.

They illustrate design controls from the documented architecture without attempting to recreate the private production configuration.

## Rules

- examples may not contain secrets;
- examples use only public documentation identifiers and addresses;
- examples are not guaranteed to be directly runnable;
- omitted settings must not be inferred to have particular production values;
- private paths, accounts, domains, and credentials are not reconstructed with fake realism.

- `compose/caddy-network-boundary.fragment.yml`
- `reverse-proxy/Caddyfile.fragment`
- `firewall-policy/README.md`
- `systemd/backup-maintenance.fragment`
